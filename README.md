# 📈 Stock Prediction V2

An end-to-end Machine Learning and Deep Learning project for stock market prediction.

## Features

- Data Collection from Yahoo Finance
- Data Cleaning & Preprocessing
- Feature Engineering
- Walk-Forward Validation
- Random Forest
- XGBoost
- LightGBM
- CatBoost
- SHAP Explainability
- Portfolio Backtesting
- PyTorch LSTM (In Progress)
